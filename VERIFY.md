# VERIFY: sandbox checks to run by hand

The app never calls PayPal or Anthropic on its own in this repository's tests. Everything below needs a human with a PayPal sandbox app. Each item names the code path that makes the call, the order to run things, and what to do if it fails. Run them in this order: item 1 first, because every later item depends on Transaction Search being open.

Setup for all items: create a sandbox REST app with Transaction Search, Invoicing and Payments enabled, then set `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `APPROVAL_SECRET` and run `npm start`. Without keys the app runs on the mock and none of this applies.
